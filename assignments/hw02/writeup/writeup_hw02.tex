\section*{Problem 1}
In this problem, we use the OnlineNews dataset available on Canvas.  The dataset is
about predicting the popularity of websites from 58 features.  Discard the first two
variables from the data.  From the remaining variables use all but the last variable as 
predictors and the log of the last variable.

Obtain all results using 5-fold cross-validation, which is computed as follows:

\begin{enumerate}
    \item Generate a random permutation of the data.  Use this randomized permutation to 
    split the data into 5 disjoint subsets of almost equal size.
    \item For each fold \(i\in\{1,\dots, 5\}\), train the model on all data except subset \(i\) and test
    it on subset \(i\), obtaining test error \(\epsilon_i\).
    \item Obtain the final test error as the average of the 5 test errors \(\epsilon_i\) obtained above.
\end{enumerate}

Report results for the following models:

\begin{itemize}
    \item Null model.  Report the average train and test MSE of the null model that always predicts training 
    \(\bar{y}\) (average training \(y\))

    We do this in Python and obtain a train MSE of 0.8657 and a test MSE of 0.8658. 

    \item OLS regression computed analytically by solving the following normal equations:
    
    \[(\frac{1}{N}X^T X + \lambda I_p)\beta = \frac{1}{N}X^T Y\]

    where \(\lambda = \in \{0,10^{-5}, 10^{-4}, 10^{-3}, 10^{-2}, 10^{-1}\}\) and N is the number of observations
    in X.  Report in a table the average training and test \(R^2\) and MSE, as well as their standard 
    deviations obtained from the 5 folds.  On the same graph, plot the average training and test MSE vs \(\lambda\)
    as two seperate curves.  Also plot the average value of the logarithm of the determinant of 
    \(\frac{1}{N}X^T X + \lambda I_p\) vs \(\lambda\).
